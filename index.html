Ton téléphone fait
le Bluetooth de ton PC

Connecte ta manette en Bluetooth à ton téléphone : il la transmet à ton PC en Wi-Fi. Pas besoin de Bluetooth sur le PC, pas de câble.

⬇ Télécharger pour Windows ☕ Soutenir le projet 📱 Android (bêta)

Gratuit · Windows 10 et 11 · Le code source est public

Comment ça marche

1

Installe sur ton PC

Télécharge l'installateur et lance-le. Il installe aussi le pilote nécessaire pour que Windows reconnaisse la manette.

2

Relie ta manette au téléphone

Associe ta manette à ton téléphone en Bluetooth, comme d'habitude. Puis ouvre l'application Manette Virtuelle Phone (Android) et tape le code à 4 chiffres affiché par le programme : elle trouve ton PC toute seule. Sur iPhone, ouvre dans Safari l'adresse affichée par le programme.

3

Joue sur ton PC

Ton PC voit une manette de type Xbox 360. Elle fonctionne avec les jeux qui acceptent une manette.

Ce que tu peux faire

📡 Ta manette Bluetooth sur PC

Boutons, sticks et gâchettes de ta manette sont transmis au PC, palettes de dos comprises (tu choisis à quel bouton elles correspondent).

👆 Manette tactile en secours

Pas de manette sous la main ? Utilise l'écran du téléphone : boutons, croix directionnelle, sticks et gâchettes.

🔒 Protégé par un code

Un nouveau code est généré à chaque lancement. Personne d'autre sur ton réseau ne peut prendre le contrôle.

⚡ Faible latence

La latence s'affiche en direct sur ton téléphone pour que tu saches où tu en es.

📱 Application Android (bêta)

Manette Virtuelle Phone trouve ton PC avec le seul code à 4 chiffres, et une bulle flottante garde la manette active quand tu utilises d'autres applications.

Manette Virtuelle Phone (Android)

1

Télécharge l'application

Touche le bouton ci-dessous depuis ton téléphone Android. Le fichier s'appelle ManetteVirtuellePhone.apk.

2

Autorise l'installation

Android demande l'autorisation d'installer une application qui ne vient pas du Play Store. Accepte, puis ouvre le fichier téléchargé.

3

Tape le code du PC

Ouvre l'application et tape le code à 4 chiffres affiché par le programme sur le PC. Elle trouve ton PC toute seule sur le Wi-Fi.

Questions fréquentes

Windows affiche « Windows a protégé votre ordinateur »

C'est normal : le programme n'est pas signé par un éditeur payant. Clique sur « Informations complémentaires » puis « Exécuter quand même ». Le code source est public si tu veux vérifier ce que fait le programme.

Mon antivirus signale le fichier

Les programmes créés avec Python déclenchent parfois de fausses alertes. Tu peux consulter le code source sur GitHub, ou ajouter une exception pour le dossier du programme.

Le téléphone n'arrive pas à se connecter

Vérifie que le PC et le téléphone sont sur le même réseau Wi-Fi, et que tu as autorisé le programme sur les réseaux privés dans le pare-feu Windows lors du premier lancement.

Pourquoi un pilote est-il installé ?

Le pilote ViGEmBus permet à Windows de voir une manette virtuelle. Sans lui, aucun jeu ne peut recevoir les commandes.

Mon PC n'a pas de Bluetooth, ça marche ?

Oui, c'est fait pour ça. Seul ton téléphone a besoin du Bluetooth. Le PC, lui, reçoit tout par le réseau : il doit simplement être sur le même Wi-Fi (ou relié par câble au même réseau) que le téléphone.

La manette s'arrête quand j'utilise une autre application sur le téléphone

C'est une règle d'Android : la manette n'est envoyée qu'à l'application ou à la page qui est au premier plan. Avec l'application Manette Virtuelle Phone, active la bulle flottante : elle garde la manette active quand tu quittes l'application, et tu la touches pour reprendre la manette après avoir utilisé autre chose. Avec la page web (iPhone), garde la page ouverte pendant que tu joues.

Android bloque l'installation de l'application

C'est normal : l'application ne vient pas du Play Store. Quand Android le propose, autorise ton navigateur ou ton gestionnaire de fichiers à installer des applications, puis relance l'installation. Google Play Protect peut afficher un avertissement pour les applications qu'il ne connaît pas : le code source est public si tu veux vérifier ce que fait l'application.

Quelles manettes sont compatibles ?

Celles que ton téléphone reconnaît en Bluetooth et que son navigateur sait lire. Les manettes courantes de type Xbox ou PlayStation fonctionnent généralement, mais ça peut varier selon le téléphone.

Ça marche sur Mac, Linux ou console ?

Non, uniquement Windows pour le PC pour l'instant. Côté téléphone : une application pour Android (bêta), et la page web dans Safari pour iPhone.
